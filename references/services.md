# Common profile image services

All are public instances and may be rate-limited or become paid. Check with curl after every generation; remove or replace any that fail. Status as tested in 2026-10.

| Use | URL | Status |
| --- | --- | --- |
| Typing animation | `https://readme-typing-svg.demolab.com?font=Fira+Code&weight=600&size=24&duration=3000&pause=800&color=2F81F7&center=true&vCenter=true&width=620&lines=Line+one;Line+two` | Works. English text only; Chinese fonts render unreliably |
| Tech icon wall | `https://skillicons.dev/icons?i=python,fastapi,redis,docker&perline=12` | Works. Icon names at skillicons.dev; write missing technologies as text |
| Badge | `https://img.shields.io/badge/<name>-<color>?logo=<simpleicons-name>&logoColor=white` | Works |
| Stats card | `https://github-readme-stats.vercel.app/api?username=<login>&show_icons=true` | Works, but the public instance is often rate-limited; skip when the user has little data |
| Commit streak | `https://streak-stats.demolab.com?user=<login>` | Works |
| Activity graph | `github-readme-activity-graph.vercel.app` | Returned 402 in 2026-10, don't use |
| Contribution snake | Generated by assets/snake.yml (Platane/snk@v3) into the output branch | Works, needs workflow scope |

Snake in the README:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/<login>/<login>/output/github-snake-dark.svg" />
  <img src="https://raw.githubusercontent.com/<login>/<login>/output/github-snake.svg" alt="Contribution snake" />
</picture>
```

Style examples are in showcase.md.
