# Style showcase

Used in step 1: style options and example links come from here. Each style has two real profiles; opening one shows exactly what a published profile looks like (avatar and info on the left, README on the right, pinned repos and the contribution grid below).

Examples verified to exist on 2026-10-26.

## What to send the user

Translate the descriptions into the user's language; keep the URLs as they are.

1. **Comprehensive**: typing animation, tech icons, project intros, contribution snake
   https://github.com/mizane446
   https://github.com/DenverCoder1
2. **Minimalist text**: a few lines and links, the work speaks for itself; common among well-known developers
   https://github.com/tw93
   https://github.com/simonw
3. **Stats cards**: cards for stars, commits, top languages, commit streak
   https://github.com/anuraghazra
   https://github.com/ouuan
4. **GIFs and emoji**: animated GIFs and emoji, playful
   https://github.com/Prince-Shivaram
   https://github.com/innng

**More styles** (code art, games, anime, retro and more, 16 categories):
https://github.com/abhisheknaiidu/awesome-github-profile-readme
Scroll down to Categories and click a category name; each line is one person. Note: links in that list open the person's same-name repo (`github.com/name/name`), not the profile. Delete the last `/name` and press Enter, or click the name at the top left, to reach the real profile. Paste back any link you like; either form works.

## Which one to follow when generating

If the user picked a number, read the README source of the first profile in that style. If they pasted another link (`github.com/<u>` or `github.com/<u>/<u>`), read that one.

If the user picks stats cards but has very few stars and followers, warn once that the card numbers will be small and suggest Comprehensive. If they insist, do as they ask.
