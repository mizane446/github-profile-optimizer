# 风格展示清单

第 1 步用：风格选项和样例链接取自这里。每种风格两个真实主页，用户点开看到的就是上线后的样子（左边头像资料，右边 README，往下是置顶仓库和贡献格子）。

样例于 2026-10-26 核实存在。

## 发给用户的内容

1. **综合展示**：打字动画、技术图标、项目介绍、贡献贪吃蛇
   https://github.com/mizane446
   https://github.com/DenverCoder1
2. **极简文字**：几行字加链接，靠作品说话，大牛常用
   https://github.com/tw93
   https://github.com/simonw
3. **数据卡片**：Star、提交数、常用语言、连续提交天数等统计卡片
   https://github.com/anuraghazra
   https://github.com/ouuan
4. **动图表情**：放 GIF 动图和表情，活泼
   https://github.com/Prince-Shivaram
   https://github.com/innng

**想看更多风格**（代码风、游戏互动、二次元、复古等 16 类）：
https://github.com/abhisheknaiidu/awesome-github-profile-readme
打开后往下翻到 Categories，点分类名跳到该类，每行一个人名。注意：合集里的链接打开的是他的同名仓库（地址形如 github.com/名字/名字），不是主页；把地址最后的 /名字 删掉回车，或点左上角的名字，就进到真实主页。看中哪个，把链接贴回来，两种地址都行。

## 生成时参考哪个

用户选了编号，读该风格第一个主页的 README 源码；贴了别的链接（`github.com/<u>` 或 `github.com/<u>/<u>` 都行）就读那个。

用户选数据卡片但 Star 和关注者都很少时，提醒一句“卡片数字会很小”，建议综合展示，用户坚持就照做。
